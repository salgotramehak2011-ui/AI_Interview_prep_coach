# Frontend — Streamlit UI

## Run

```bash
cd frontend
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Ensure the FastAPI backend is running at `http://localhost:8000`.

Configure API URL in the sidebar if needed.

## Pages

- **Dashboard** — overview and domain progress
- **Interview** — live chat-style mock interview
- **Analytics** — scores, trends, roadmap
- **Weak Areas** — charts and improvement suggestions
